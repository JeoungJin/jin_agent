## 구성
- **필수**: 3 토론 → 4 미션 1(순차 Manager-Worker, 권한 분리) → 5 미션 2(그래프 API 연결, 7단계 E2E, 장애 주입, 골든 질문) → 6 README → 7 발표·회고
- **선택 심화(8절)**: 병렬 Worker(Send API)와 Reducer 실험. 하지 않아도 마무리에 영향 없음.
- 병렬이 아닌 순차를 필수로 둔 이유: 병렬의 이점은 속도이고, 멀티에이전트의 핵심 이점인 권한 분리는 순차에서도 유지됨.

## 원본 대비 추가·정리한 부분
- 5절 미션 2에 **그래프를 `/route`·`/route-stream`에 연결**하는 프롬프트 추가 (원본의 E2E 체크리스트가 Spring·React를 통과하므로 필요). 스위치 `AGENT_GRAPH_ENABLED`로 기존 루프로 되돌릴 수 있게 함.
- 원본의 "환각검증"은 구현된 적이 없어 **골든 질문(최소 환각 검증)** 도구 프롬프트로 구체화.
- Worker는 새 뉴스·리스크 도구 대신 기존 도구(시세·환율, 문서 검색, 계좌)로 구성.
- README 작성 시 사례·한계는 학생 메모만 쓰게 하는 AI 초안 프롬프트 추가.
