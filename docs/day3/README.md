# Day 3 교육생 자료

| 파일 | 설명 |
|---|---|
| `Day3_AI_Agent(Student).docx` | Day 2와 같은 형식의 교육생 자료. 시간 표시 없음, 프롬프트는 `[범위]·[계약]·[요구사항]` 구조로 정리, 개념 설명은 본문에 포함 |
| `images/` | 이미지 (PNG, SVG). `d3-r*` = 기존 Day 3 문서의 그림(일부 수정), `d3-s*` = 완성 화면 캡처, `d3-01~08` = 새로 추가한 그림 |
| `build/` | 문서·이미지 생성 스크립트 |

기존 그림 중 `d3-r1`(streaming-compare), `d3-r4`(streaming-consistency)는 스트리밍 주소가 `/route`로 적혀 있어 현재 프롬프트(`/route-stream`)에 맞게 고쳐 다시 그렸다.
